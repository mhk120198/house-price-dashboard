# 🏡 House Price Prediction & Interactive Dashboard

An end-to-end Data Science and Machine Learning project built using Python, Scikit-Learn, and Streamlit.

## 📌 Features
- Data processing and model training pipeline.
- Random Forest Regressor model predicting house prices based on Square Footage, Bedrooms, and Age.
- Interactive web dashboard for real-time predictions.

## 📁 Project Structure
house-price-dashboard/
|-- data/        # CSV dataset
|-- models/      # Trained Machine Learning model (.joblib)
|-- src/         # Python training script
|-- app/         # Streamlit web and PowerBI dashboard
